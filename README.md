# リファレンス検索ワード棚

アニメ・ゲーム制作用の**英語リファレンス検索ワード66本**を、ゲームショップの棚のように眺めて選べるページです。
英語が苦手でも「検索すると何が出てくるか」が日本語で分かります。

**使い方**

1. カードにカーソルを合わせる → 何の動きで、検索すると何が出るかが日本語で出ます
2. クリック → 英語の検索ワードをコピー
3. YouTube の検索欄に貼り付け（Ctrl+V / ⌘V）
4. 右クリック（スマホは長押し）→ プロが使う技名メニュー

**入っているもの**

- 10棚 66本：移動 / 跳ぶ・登る / 打撃 / 組み技 / 剣・刀 / 長物・鈍器 / 銃 / 弓・投擲 / やられ / 日常・演技
- 武器の棚は**種類セレクター**つき。ハンドガンを選べば `pistol reload reference`、ショットガンなら `shotgun reload reference` に切り替わります
- 右クリックで出る専門ワード（技名）約230件
- 「棚」表示と「一覧表」表示の切り替え、日本語・英語どちらでも効く絞り込み検索

## 公開について

`index.html` 1枚だけで動きます。ビルドもサーバーも不要です。
GitHub Pages で公開する場合は、リポジトリの **Settings → Pages → Source: Deploy from a branch → main / (root)** を選ぶだけです。

外部から読み込んでいるのは Google Fonts のみ。データはすべて `index.html` の中に入っています。
